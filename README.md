# Image Converter

Утилита для конвертации изображений между форматами JPEG, PPM и BMP (не сжатый, 24-битный)

Этот проект — консольный конвертер изображений, построенный на собственной библиотеке ImgLib, которая реализует загрузку и сохранение изображений в нескольких популярных форматах. Благодаря модульной архитектуре и единообразному интерфейсу обработки форматов проект легко расширяется новыми типами изображений.

---

## Возможности проекта

### 1. Конвертация между форматами

Поддерживаются форматы:

* JPEG — через библиотеку *LibJPEG*
* PPM (P6) — собственная реализация
* BMP (24-bit, без компрессии) — собственная реализация

  * строгая проверка заголовков
  * BGR-порядок пикселей
  * поддержка паддинга по строкам

### 2. Унифицированный интерфейс обработки форматов

Каждый формат реализует общий интерфейс:

```cpp
class ImageFormatInterface {
public:
    virtual bool SaveImage(...) const = 0;
    virtual img_lib::Image LoadImage(...) const = 0;
};
```
Это делает архитектуру гибкой и позволяет легко добавлять новые форматы.

### 3. Собственная библиотека ImgLib

ImgLib включает:

* контейнер изображения img_lib::Image
* функции загрузки/сохранения: LoadPPM, SaveJPEG, LoadBMP и др.
* поддержку LibJPEG как внешней зависимости
* аккуратное управление памятью и безопасное API

## Как работает конвертер

Приложение определяет формат файла по его расширению:

```cpp
Format GetFormatByExtension(const img_lib::Path& input_file);
```
Для каждого формата существует своя реализация **ImageFormatInterface**:

* FormatPPM
* FormatJPEG
* FormatBMP

Алгоритм конвертации:

1. Определить входной и выходной формат
2. Загрузить изображение через соответствующий интерфейс
3. Проверить корректность
4. Сохранить изображение в новом формате

---

## Поддержка BMP

Проект поддерживает строго определённый вид BMP-файлов:

* 24-bit
* без компрессии (compression = 0)
* заголовки BitmapFileHeader = 14 байт, BitmapInfoHeader = 40 байт
* обратный порядок строк (bottom-up)
* выравнивание строк по 4 байта

Если BMP-файл не соответствует этим требованиям, он будет отклонён.

## Компиляция

### Совместимость платформ


| Платформа |	Компилятор	| Статус	        |   Примечания                  |
| --------- | ------------- | ----------------- | ------------------------------|
| Windows   |	MinGW	    | Поддерживается	| Основная платформа            |
| Windows   |	MSVC	    | Не поддерживается | Требует LibJPEG для MSVC      |
| Linux     |	GCC/Clang	| Возможна	        | Нужна перекомпиляция LibJPEG  |
| MacOS     |	Clang	    | Возможна	        | Нужна перекомпиляция LibJPEG  |

__Проект переносим, но зависимость LibJPEG требует сборки под целевую платформу.__


### ImgLib CMake

ImgLib требует указать путь к статической сборке LibJPEG: `-DLIBJPEG_DIR=<путь_к_libjpeg>`  


### ImgConverter CMake

ImgConverter подключает ImgLib как зависимость:

```cmake
add_subdirectory(../ImgLib ImgLibBuildDir)
target_link_libraries(imgconv ImgLib)
```

### Сборка:

```bash
# Из ImgConverter
mkdir build && cd build
cmake .. -G "MinGW Makefiles" -DLIBJPEG_DIR="..\ImgLib\libjpeg"
cmake --build .
```

## Использование

Запуск программы:

```bash
imgconv.exe input.jpg output.ppm
```
Форматы определяются автоматически по расширению.

Ошибки имеют читаемые коды:

| Код | Ошибка                             |
| --- | ---------------------------------- |
| 1   | Неверное количество аргументов     |
| 2   | Неизвестный формат входного файла  |
| 3   | Неизвестный формат выходного файла |
| 4   | Ошибка загрузки                    |
| 5   | Ошибка сохранения                  |

## Архитектура ImgLib

### 1. Контейнер Image

```cpp
class Image {
    int width_;
    int height_;
    int step_;
    std::vector<Color> pixels_;
};
```
* построчный доступ через `GetLine(y)`
* пиксели содержат RGBA
* корректность изображения проверяется через `operator bool()`

### 2. Реализация форматов

Каждый формат чётко разделён на:
* чтение/парсинг заголовков
* валидацию
* загрузку пиксельных данных
* преобразование к структуре Image

### 3. Внешняя зависимость — LibJPEG

Используется:

* jpeg_compress_struct
* jpeg_decompress_struct
